C++ 刷题 · v2.6

600 题 · 纸感浅色 · 墨黑字 · 单暖橙｜可直接点按交互

这一版改了什么

  • 退出能接着做：以前刷到第 30 题退出，再进来又从第 1 题开始；现在每次翻页都记下「第几题 + 已答的答案」，再点同一个入口直接回到那一题，首页格子上还会写「继续 · 第 7 题」
  • 题数可选：点练习先问「这一轮刷多少题」——10 / 20 / 50 / 全部，不再一律从头刷到尾巴
  • 没作答也能跳过：底部按钮在没选答案时写「跳过」，选了才写「下一题」，不再弹「请先作答」拦着你
  • 错题本 / 收藏不再空白：题目 id 索引以前要等在线题库加载后才建，没有缓存时永远是空的，于是「有 12 道错题、点进去一道没有」；现在模块加载即建索引，且查不到时自动清理失效 id
  • 左上角返回键修好了：之前自定义导航栏的 box-sizing 把按钮顶进了状态栏，灵动岛机型（iPhone 15/16/17 系列）看得见却点不着；现在热区放大到 44pt，底座落在标题行内
  • 练习页标题不再一律「顺序练习」：从分类进来显示「算法 · 顺序练习」，考试 / 错题 / 收藏各显示自己的名字，题头再补一枚分类小标签
  • 题库扩到 600 题：语法 / 算法 / 面试各 200，每题都带「为什么」式解析
  • 题库不打包开源题：开源题运行时在线拉取，包体里只有这 600 道中文题
  • 新增题库页：每个来源可单独开关、单独刷新，看得见缓存了多少题
  • 新增书架：6 本免费可读（含中文开源书）+ 6 本经典书目
  • 界面全换：深色渐变 → 米白纸底 + 衬线数字 + 一个暖橙
