# v3.0 质量与验证记录

日期：2026-10-25。目标：校招／实习 C++ 面试，从基础到进阶。

## 题库

总量 750；新增原创 150，带代码 74，多选 26。每道新增题含来源性质、考点、解释、面试追问和阅读参考。题干与代码联合去空白后无完全重复；同一知识点可以有不同场景，不宣称语义去重已穷尽。

三个新增分片分别编写并做结构自检；现代 C++ 与算法工程题另经交叉语义复核，系统题由主执行者阅读审查。交叉复核发现 ai020 对具体输入的限定使干扰选项也成立，已将该选项明确为“对任意输入”的错误泛化。

旧题重点修订：
- i101–i106：虚表属于 ABI 实现、sizeof 前提、派生类指针仍可虚分派、构造期间虚调用、inline 的 ODR 含义、去虚化与语言语义。
- i138：volatile 不意味着绕过 CPU 缓存，也不建立线程同步。
- i152：去除未经限定的协程耗时与规模数字。
- i153：页级内存保护不能简单等同于每次数组越界都被检测。
- i18：空指针调用非静态成员函数是未定义行为，不能推断必定成功或崩溃。
- s53：set::extract 的旧解析由 C++11 改为 C++17。
- s133、i114：原有重复题改为同主题的锁管理及对象池前提分析，保留 ID。

旧版题并未全部完成逐句技术审稿；标签部分来自关键词规则，可能需要继续人工调整。参考链接是学习资料，不是企业题目来源。未声称全部链接均联网验证，也未用本机 C++ 编译器执行全部代码片段。

## 行为修复

- 重复刷一道题不再抬高已练覆盖率；随机“全部”不再截断为20题。
- 普通练习跳过题在完成时进入错题本；多选重复确认不重复计数。
- 考试基于时间差处理前后台切换，普通练习后台暂停计时。
- 重练保留题数和筛选；重开页面卸载不复活已清除的进度。
- 不同筛选不串续做；空筛选不会清掉其他错题。
- 远程题不能以相同 ID 覆盖内置题或重复占用题数。
- JSON 与文本导入拒绝非法、重复和越界答案，避免显示成功但未实际入库。
- 新增题细标签映射到可见考点，保留旧题的关键词筛选。

## 验证边界
