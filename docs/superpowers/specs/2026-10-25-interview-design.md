# C++ 校招面试训练设计

用户目标：面向校招／实习，从基础到进阶准备 C++ 面试，关注腾讯、小米、字节等企业；提升题目质量、数量、界面及稳定性。

方案：在原生微信小程序中增量建设学习中心，沿用现有练习、错题、收藏与存储。相比单纯扩充选择题，本方案增加阶段、岗位、考点筛选和面试追问；相比重写为 Web 应用，保留现有用户和发布方式。此实现方案由开发者根据用户交付设计的要求选择。

- 基础 / 进阶 / 冲刺对应难度 1 / 2 / 3；可跨阶段练习。
- 通用校招、后台服务、客户端方向按知识点组织，企业名称只作用户目标语境，不宣称历年真题或命中率。
- 增加 150 道原创场景题：现代 C++、系统并发网络、算法工程各 50。附参考资料、解析、追问与回答要点；参考链接不是题目来源证明。
- 首页突出学习中心，学习中心支持交叉筛选、搜索、题数选择、开始练习与继续上次；练习页展示追问和复制参考链接。
- 修正已发现的旧题错误，保留所有旧 id。将无逐题来源的“面试真题”改为“面试核心”。
- 修复进度按次数计算、随机全部只取20、跳过不进错题本、重复多选提交、远程同id覆盖内置题、导入非法答案、结果重练丢题数、考试后台计时失准。
- 保留原业务：未答可跳过，完成时按错计算；现有续做位置判定不改，交卷清理进度；练习筛选作为新增快照字段，兼容旧数据。
- 浏览器预览同步主要界面和筛选；清楚标注示例记录，微信版才是学习记录真实运行环境。

边界：不增加账号、云端代码执行或AI打分；算法追问要求用户在本地 IDE 手写验证。不开采商业题库，不部署或发布。保持 nav content-box、旧存储键和依赖为零的运行方式。

验收：原检查与续做测试通过；新增筛选、抽题、去重、数据校验、计时及记录回归通过；检查移动视口预览。真机最终发布验收需微信开发者工具。
