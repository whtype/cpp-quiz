# C++ 面试自测与内容修正

用户目标：在远程最新版上改善校招/实习 C++ 面试准备；保持按课程章节、直接刷题的简单结构。

设计：保留 750 道选择题和所有旧记录；首页增加一条面试自测入口，章节页可进入当前章节。独立 24 张原创训练卡，覆盖 12 个现有 C++ 章节，提供口述与手写、回答要点、易错点和追问。先回答再展开要点，自评“还不会/需巩固/能讲清”，建议 1/3/7 天后复习；每轮最多 5 张，到期与未练优先。自评不等于自动判题或面试通过率，不提供在线代码执行。自测按章节保留草稿与进度，和原选择题统计分开。

实施顺序：
1. data/interview-cards.js：独立编写 24 张卡；修正旧题已确认的标准边界和单选歧义，保留 ID。
2. utils/interview.js：纯状态模型，红绿测试覆盖到期优先、章节隔离、先揭示后评价、重复点击、草稿恢复与旧数据兼容。
3. pages/interview 四件套、preview-interview.js/css：两端统一入口和流程。浏览器使用 WebStore 原有偏好接口保存自测状态。
4. 检查内容、页面逻辑、网页端刷新，运行所有原有测试和新增回归。
5. 更新 README/QUALITY/DEVLOG，提交推送原仓库并确认 GitHub Pages 发布。

验证边界：只能改进训练工具和内容；不宣称覆盖所有面试问题。微信真机、全部旧题逐句技术审稿另行标注。
