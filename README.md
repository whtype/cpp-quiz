# C++ 刷题 v2.8

一个直接开始练习的 C++ 刷题工具，提供网页版和微信小程序：每轮最多 20 题，做题、看解析、复习错题。

**在线测试：[https://whtype.github.io/cpp-quiz/](https://whtype.github.io/cpp-quiz/)**

直接把这个链接发给别人，用手机或电脑浏览器打开即可，无需启动本地服务。网页端真实保存答题记录、错题、收藏、导入题目和续做进度，数据存在各自浏览器，不跨设备同步；清除网站数据会丢失记录。

## 这一版

- 新增 **面试自测**：24 张原创训练卡，覆盖 12 个 C++ 章节（17 口述 + 7 手写），包含回答要点、常见误区、追问与参考资料。
- 每轮最多 5 张，先独立作答再展开要点；按自评建议 1 / 3 / 7 天后复习，到期优先。章节草稿与进度自动保存，自评不会计入选择题正确率。
- 修正 20 道旧题的标准前提、解析或单选歧义，保留全部题目 ID。

- **750 道内置题**：原有 600 题 + 150 道原创场景题，无需联网也能练。
- 首页一个主按钮：开始刷题；有未完成进度时显示继续上次。
- 可选基础、进阶、全部难度；按课程章节专项练习，不分岗位方向。
- 新增题全部含解析、追问及回答要点、参考资料；其中 74 道含代码，26 道多选。
- 每轮优先出没做过的题，保留续做、错题、收藏、在线题库、导入及书架。
- 首页进度按**练过的不同题目**统计，正确率仍按累计作答次数统计。

| 分类 | 内置题量 |
|---|---:|
| C++ 语法基础 | 220 |
| 算法与数据结构 | 230 |

| 现代 C++ | 50 |

难度分布：基础 103、进阶 471、较难 176；“全部难度”包含所有难度。

## 推荐用法

1. 首页直接点“开始刷题”，默认从基础开始，每轮 20 题。
2. 答题后看解析；想进一步理解时再展开“延伸理解（选看）”。
3. 做错的题到错题本复习，退出后可继续未完成的练习。
4. 想专项练习，点击“按章节练习 / 调整难度”，选择数组、字符串、函数、指针与引用、类、内存管理、STL、模板、异常处理等章节。切换章节默认全部难度，也可以再选基础或进阶。

## 怎样用来准备面试

每天先练 20 道章节选择题，再做 5 道“面试自测”。口述题先用自己的话解释原因和边界，手写题先完成代码再对照参考实现，并在自己的 C++17 环境编译、运行边界用例。读懂解析但不能独立回答时，选“还不会”或“需巩固”。

自测是个人评价，不自动判定代码正确，也不是面试通过率；仍需结合真实项目经历与算法实现练习。网页版与微信小程序均提供自测入口。

## 题目质量

“面试真题”已更名为“面试核心”：旧题没有逐题出处，不能作为公司真题宣传。

本次修正了虚函数分派、对象布局假设、inline、空指针调用、C++17 extract、volatile 与协程性能等错误或不严谨表述。两组完全相同的题干改为同主题场景题，旧 ID 保留。新增题参考链接用于延伸阅读，并不表示原网站提供了该题或已人工背书。

[质量说明与验证记录](docs/QUALITY.md) 记录审查范围和已知限制。结构校验不能证明所有技术结论；原有 600 题仍需要持续逐题复核。

## 本地使用

**微信小程序**：微信开发者工具导入本目录，入口为 `app.json`。真机在线题库需配置合法域名或云函数，见 [UPLOAD.md](UPLOAD.md)。

**浏览器预览**：打开 `preview.html`，或运行：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8765/preview.html`。`#learn` 可直达章节和难度选择。网页与微信共用题库和记录规则；网页通过 localStorage 保存实际记录。推送 main 后由已有 GitHub Pages 自动部署，部署完成后分享链接即可更新。

## 主要文件

- `data/questions.js`：原题、题库装配和稳定 ID 索引。
- `data/bank/*-interview.js`：150 道新增题。
- `utils/learning.js`：两端共享的知识点、筛选、分领域抽题。
- `pages/learn/`：章节和难度选择；`pages/practice/`：练习和考试。
- `utils/store.js`：本地记录；保留原存储键，不迁移或清空历史数据。
- `utils/adapter.js`、`utils/sources.js`：导入适配和在线加载。
- `preview-learning.js`、`preview-learning.css`：浏览器章节和难度选择。

没有新增运行时依赖，没有账号或云端代码判题。网页版通过 GitHub Pages 发布；微信小程序仍需在开发者工具单独上传。

- `web-storage.js`：浏览器存储适配；`web-runtime.js`：真实记录、结果、续做及导入。

- `data/interview-cards.js`：24 张独立面试训练卡（不计入原 750 道选择题）。
- `utils/interview.js`：两端共用的自测、草稿、章节进度与复习顺序。
- `pages/interview/`、`preview-interview.js/css`：小程序与网页自测界面。
